- จอ Program Output เต็มจอบนจอที่เลือกได้ในแอป (Mac / Windows / Linux): กด “เลือกจอ” → เลือกจอ → หน้าต่างย้ายไปจอนั้นและเต็มจอทันที
- แอปจำจอที่เลือกไว้ เปิดหน้าต่าง Program Output ครั้งต่อไปเต็มจอบนจอนั้นเอง (ถ้าจอยังต่ออยู่) · ยกเลิกได้ในเมนู “เลือกจอ”
- ออกจากเต็มจอด้วย Esc, ปุ่ม “ออกจากเต็มจอ” หรือปุ่มเขียวของ macOS — แถบสถานะแสดงจอและสถานะเต็มจอตามจริง
- ภาพย่อบนการ์ดของวิดีโอที่กำลังเล่นลื่นขึ้น (อัปเดตทุกเฟรมเมื่อเครื่องทำทัน)
- macOS: ครั้งแรกถ้าขึ้น “Not Opened” ให้กด Done → ตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → Open Anyway
