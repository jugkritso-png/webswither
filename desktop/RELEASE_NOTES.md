- เครื่องเบาลงตอนไลฟ์: วิดีโอที่หยุดอยู่หรือไม่มีภาพใหม่ไม่ถูกส่งไปการ์ดจอซ้ำทุกเฟรมแล้ว
- ลดงานเองเมื่อเครื่องทำไม่ทัน: วาดจอ Preview และภาพย่อบนการ์ดห่างขึ้น (ผู้ชมไม่เห็น) ให้ภาพไลฟ์ได้เฟรมเรตเต็ม · แถบสถานะขึ้น “ลดงาน Preview” · เบาลงแล้วกลับเป็นปกติเอง
- บอกว่าแหล่งภาพไหนทำให้เครื่องหนัก: ข้อความเตือนพร้อมชื่อและความละเอียด · กด “ดูวิธีแก้” ดูเวลาที่แต่ละแหล่งใช้และวิธีแก้
- ผลทดสอบตัวเองของแอปเดสก์ท็อปตรวจชิปเข้ารหัส H.264 ของเครื่อง และวัดความเร็ววาดภาพ
- macOS: ครั้งแรกถ้าขึ้น “Not Opened” ให้กด Done → ตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → Open Anyway
