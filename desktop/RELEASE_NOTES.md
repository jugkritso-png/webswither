- CG Studio แบบกราฟิกงานข่าว: เทมเพลตใหม่ทั้ง 6 แบบ (Lower Third 2 ชั้น, แถบหัวข้อ, ป้าย LIVE, ตัววิ่ง, ป้ายคะแนน, ประกาศเต็มจอ) อยู่ในเขต Title Safe 90% พื้นไล่สีพร้อมเงา · ข้อความยาวย่อให้พอดีช่องแทนการบีบตัวอักษร · ตั้งระยะตัวอักษร ตัวพิมพ์ใหญ่ จัดกึ่งกลางแนวตั้ง และไล่สีได้ · กรอบ Safe area มาตรฐาน HD (Title 90% / Action 93%)
- Gateway สำรอง: ตั้งค่า → การสตรีม → ขั้นสูง — ถ้า Gateway หลักกำลังอัปเดต ต่อไม่ติด หรือล่มระหว่างไลฟ์ ระบบย้ายไลฟ์ไปตัวสำรองให้เอง
- เว็บ Chrome / Edge และแอปเดสก์ท็อป: เครื่องที่มีชิปเข้ารหัส H.264 ส่งภาพตรงผ่าน Gateway ไม่ต้องเข้ารหัสซ้ำ — เซิร์ฟเวอร์เบาลงมาก ภาพคมขึ้น
- เซิร์ฟเวอร์ (รัน install.sh ใหม่เพื่อรับการปรับปรุง): อัปเดตโดยไม่ตัดไลฟ์ที่ออกอากาศอยู่ · ปรับเครือข่ายสำหรับไลฟ์ (TCP BBR, บัฟเฟอร์ SRT ใหญ่ขึ้น)
