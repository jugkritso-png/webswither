- แหล่งภาพสำรองอัตโนมัติ: ตั้งค่า → เอาต์พุต → “เมื่อภาพบน Program หลุด” — ระหว่างไลฟ์หรือบันทึก ถ้ากล้อง / มือถือ / แขก / สัญญาณเครือข่ายบน Program หลุดเกินเวลาที่ตั้ง ระบบตัดไปแหล่งสำรองให้ และมีปุ่ม “กลับไป…” เมื่อสัญญาณกลับมา (หรือตั้งให้ตัดกลับเอง)
- จำนวนผู้ชมขณะนี้จาก YouTube / Facebook (ที่เชื่อมคอมเมนต์ไว้) แสดงในแถบสถานะระหว่างไลฟ์ และสรุป “ผู้ชมสูงสุด” หลังจบไลฟ์
- Android: ไลฟ์ตอนกดโฮม / ปิดจอเสถียรขึ้น — ปลุกระบบเสียงกลับทันทีเมื่อเครื่องพักไว้ ภาพที่ปลายทางได้จึงไม่สั้นกว่าเวลาจริง
- กล้องมือถือ: เมื่อสตูดิโอนำกล้องออก มือถือขึ้นข้อความแจ้งถูกต้อง (ไม่ขึ้นว่ากำลังเชื่อมต่อใหม่)
- ผ่านการทดสอบไลฟ์ต่อเนื่อง 2 ชั่วโมง: หน่วยความจำไม่รั่ว ภาพไม่ตก ไม่หลุด เสียงตรงกับภาพ
