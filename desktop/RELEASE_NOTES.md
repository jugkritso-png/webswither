- ไลฟ์ได้ทันทีโดยไม่ต้องติดตั้งอะไรเพิ่ม: แอป Windows และ macOS มีตัวเข้ารหัสวิดีโอ (ffmpeg) ในตัวแล้ว ไม่ต้องลง winget / Homebrew · ใช้การ์ดจอ NVIDIA / AMD (Windows) และชิปของ Mac เข้ารหัสได้ เครื่องเบาลง
- ตั้งเซิร์ฟเวอร์ของตัวเองโดยไม่ต้องพิมพ์คำสั่ง: ตั้งค่า → การสตรีม → ขั้นสูง → “ตั้งเซิร์ฟเวอร์ของฉัน” — เลือกผู้ให้บริการ คัดลอกข้อความไปวางตอนสร้างเครื่อง ใส่ IP แล้วแอปเชื่อมต่อให้เอง · เซิร์ฟเวอร์อัปเดตตัวเองทุกคืนโดยไม่ตัดไลฟ์
- หน้าจัดการเซิร์ฟเวอร์ (/admin): ดูไลฟ์ทุกคน · เพิ่มคนพร้อมลิงก์เชิญ (เปิดลิงก์แล้ว WebMix ตั้งค่าให้เอง) · เลือกแพ็กเกจ · พักการใช้งาน · หยุดไลฟ์ · พักรับไลฟ์ใหม่ก่อนอัปเดต
- แก้: สร้างไลฟ์ Facebook ล่วงหน้าจากในแอปใช้ไม่ได้ · ภาพตัวอย่างกล้องและเสียงในรีโมตคอนโทรลไม่ขึ้น
- จัดระเบียบโค้ดให้ดูแลง่ายขึ้น (แยกฟีเจอร์เป็นไฟล์ · ตรวจโค้ดอัตโนมัติ) — ทดสอบอัตโนมัติครบทุกระบบ
- macOS: ครั้งแรกถ้าขึ้น “Not Opened” ให้กด Done → ตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → Open Anyway
